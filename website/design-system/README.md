# AI Journey design system

The design base for the AI Journey website. It is built on the ENSIA Tech Community site (etclub.online) and extended for a bathymetric chart of a loss landscape. Open `index.html` through a local server to see every token and component in use:

```bash
cd website/design-system && python3 -m http.server 47391 --bind 127.0.0.1
# then open http://127.0.0.1:47391/   (add ?p=0.6 to open the chart mid-dive)
```

## Files

| File | What it holds |
|---|---|
| `tokens.css` | Layer 1: the club's tokens, copied unchanged. Layer 2: AI Journey extensions. Also the `chart` light theme and print overrides. |
| `base.css` | Fonts, page, type classes (`.az`, `.xp`, `.gtext`, `.outline`, `.label`, `.num`) and shapes (`.chamfer`, `.cut`). |
| `components.css` | Club components (`ETC`) and new components (`AIJ`). |
| `chart.js` | The 2D bathymetric chart. It is the site's 2D map mode and the reference for the three.js terrain shader. |
| `icons/` | The new icon set in the club's icon grammar. It is generated by `../tools/make_icons.py`. |
| `assets/club/` | Club brand files (emblem, wordmark, ENSIA logo, icons, mascots), downloaded from etclub.online on 2026-10-10. |
| `fonts/Azonix.otf` | The display face. It is the same file the club serves (Mixo/mixofx, a free font). |
| `data/spike_terrain.js` | Terrain from the feasibility test, used by the specimen chart. |

## What comes from the club

All values in Layer 1 of `tokens.css` match etclub.online's production CSS:

- **Colours:** an ocean scale (`abyss #040D12`, `deep #0A1A21`, `trench #10252E`, `foam #E9F3F1`, `fog #8FA3A6`, `ink #04140D`), the signal pair (`signal #19F08B`, `cyan #12C2F0`) and their 100° gradient, `danger`, and `plankton #7FE9F5` (the club's drifting particles). `etcode` orange is reserved for ETCode and is not used here.
- **Type:**
  - Azonix in uppercase for display text (`.az`)
  - Archivo for body text at 17px/1.55
  - expanded heavy Archivo (`.xp`: weight 800, width 125%) for titles and names
  - JetBrains Mono in uppercase with .06em tracking for labels and numbers
- **Shape:** square boxes with a cut top-right corner (`.chamfer` 12px, `.cut` 28px). No rounded corners on boxes; circles only for dots and portraits.
- **Lines and depth:** no borders. Use a 1–1.5px inset `box-shadow` in `--line` or `--line-2`, and a cyan glow on hover or selection.
- **Components kept with the same look:** sticky blurred header, gradient underline nav links, `.btn-glow` / `.btn-line` / `.btn-ink`, `.sq`, `.chip`, deep panels, the gradient panel, the stats row, progress steps (`done` / `now` / `todo`), choice buttons (`.lv`), and the right-hand depth rail.
- **Layout and motion:** `.wrap` (1320px, 16–40px gutter), section rhythm `--sec`, `ease-out` and `ease-io`.

## What is new, and why

The club site is already an ocean, with a depth rail that starts at "0 M · Surface". So the AI Journey concept becomes a dive: **loss is depth**. The extensions stay inside the club palette:

| Extension | Why |
|---|---|
| **Depth scale** `--d0`…`--d6` | Tints for the chart, from shallow water (high loss) to the abyss (low loss). They are mixed from the club's trench and cyan into abyss, so no new hue enters the palette. |
| **Routes** | Basic = `signal`, advanced = `cyan`. The journey runs along the club gradient, from its green end to its cyan end. Currents (links between the courses) use `plankton`. |
| **Isobaths** | Contour colours with Tanaka-style lit and shaded edges. Index isobaths are drawn in signal and labelled with the real loss. |
| **Chart paper theme** (`data-theme="chart"`) | A light theme for print and the A2 poster: foam paper, ink linework, darker route colours. The club site is dark only; this follows its light Read-IT card. |
| **Station card** | One per session. It has a station code (B00–B12, A00–A13), the real outcomes, two soundings and kit links. The route colour is its top edge, like the club's crew cards. |
| **Sounding** | A real measured number with the notebook section it came from. |
| **Ping card** | Guess before you see: a real pause question with club `.lv` choices, then the measured echo. |
| **Kit row** | One download: icon, name, file, size and format, action. |
| **Guide card** | One instructor, generated from data. A monogram is used when there is no photo, and an empty slot shows where the next guide goes. |
| **Depth gauge** | The club's depth rail, extended. The rail shows progress through the stations (zones Surface → Abyss); the readout shows the run's real training loss and step. |
| **Icons** | 17 new icons (surface, trench, station, sounding, ping, current, gauge, descent, guide, kit, notebook, render, cloud, zip, arrows, theme). They follow the club's grammar: 24px, 1.6 stroke, square caps, miter joins, `-f` foam and `-g` gradient files. Ping is drawn as a sonar sweep because the club's marketing icon already uses broadcast arcs. |

## Rules

1. Don't change Layer 1 values. If the club changes its site, update Layer 1 to match.
2. No rounded boxes, no new hues, no bloom. Glows are the club's cyan box-shadows only.
3. Every number shown as a sounding must come from a notebook's saved output, and its source goes in `.src`.
4. Text in Azonix is always uppercase and short (titles, codes, big numbers). Body text and session titles use Archivo.
5. Content must work without WebGL: the 2D chart, cards and kit are plain DOM and canvas.

## Decisions

- **Unit label:** "AI & Data Science Cell", as on etclub.online (decided 2026-10-10). The short form in the header is "AI & Data Science · ETC". The site reads it from `content/site.json`.
- **Azonix licence:** fine to use (the club already serves it).
- **Emblem:** the club's SVG (2026-10-10), rebuilt from a 667 KB gradient-mesh export into clean paths with the original gradient stops: `etc-emblem.svg` (full, 9.5 KB) and `etc-mark.svg` (no ring text, for small sizes, 5.9 KB). The original is kept in `brand/source/`. The WebP is no longer used.
