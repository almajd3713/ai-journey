Evaluation: When Is a Model Good?

We start with a model that scores 99% and is useless, then build an evaluation procedure in a fixed order so the final score is honest.

By the end you can
  1. say why accuracy can mislead, and read a confusion matrix, precision and recall instead;
  2. choose a decision threshold from a stated policy, using data that is not the test set;
  3. follow the order tune → choose threshold → lock → test once.

Ping · B04 Guess before you see

Fraud detection, 1% of transactions are fraud. A model scores 99.1% accuracy on the test set. Would you put it into use?

Echo · measured

A rule that always answers "no fraud" scores 0.990 and finds none of the 50 frauds. The logistic regression scores 0.991 and finds 5 of 50. It misses 45. When one class is rare, accuracy is dominated by the common class.
