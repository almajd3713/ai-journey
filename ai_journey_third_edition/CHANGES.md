# Changes in the third edition

The October 2026 revision is described first; the original third-edition changes follow it.


## Revision of 2026-10

Done after a content review (`../BASIC_CONTENT_REVIEW.md`) and following its plan (`../BASIC_REVISION_PLAN.md`). The audience is now stated as people new to machine learning, typically software engineers. Every notebook was re-run in one Python 3.12 environment (`requirements.txt`), and every number in the text was checked against the new outputs. Sessions 3, 4, 5 and 11 reproduced their earlier outputs exactly in the new environment; Session 1 differs only in how pandas 3 names text columns.

- **Framework:** Sessions 6–10 were ported from Keras/TensorFlow to PyTorch, with plain `torch.nn` and a visible training loop, so the whole course uses one deep-learning library and one environment. Where PyTorch's defaults changed a lesson, the change is stated in the notebook: Session 7's run B uses a learning rate of 0.3 (at 1.0 the network dies on the first step), its L2 penalty covers the hidden layers only, as before, and its softmax bug is now softmax over the batch; Session 10's LSTM starts with small word vectors and an open forget gate, as Keras did. GPU runs are made deterministic, and each was run twice to check.
- **Session 0:** course map in the title cell; a hand-written rule (petal length, then width) as a second comparison, which scores 0.947 against the model's 0.921; a second pause before the confusion matrix; a timeline of the field (1936–2022), every date checked against a source (`_build/history_sources.md`).
- **Session 1:** about 20 stale numbers rewritten from the outputs (medians, threshold groups, department rates, correlations, 312 passed / 62.4%); the counts the text quotes are now printed; a second pause before the department table.
- **Session 2:** cross-validation now comes straight after the first model, so the pause "test above training?" is answered at once; leakage is section 7.
- **Session 3:** gradient-boosted trees named in the takeaways and explained in Going deeper (Breiman 2001, Friedman 2001), without new results.
- **Session 5:** the starting-centres description fixed (three of the four start in or next to the top-middle group); the history of k-means (Lloyd 1957, MacQueen 1967).
- **Session 6:** new section "How a model learns": a single unit trained with hand-written gradient descent in NumPy on versicolor and virginica, the loss and the moving boundary plotted, then the same gradient from PyTorch's autograd. Loss, gradient, learning rate and epoch are defined in the main path for the first time. The XOR network is trained with the same loop in PyTorch. History of the perceptron, Minsky and Papert, and backpropagation.
- **Session 7:** ported; every value the text reads off a curve is now printed. New result: run B's loss is stuck at 2.50 while its accuracy is 88.5%, explained by two training points that are wrong with complete certainty.
- **Session 8:** ported (same architectures and parameter counts); dense 0.931, CNN 0.973; shift test and pooling heads re-run; a pause before the parameter counts.
- **Session 9:** ported to torchvision's MobileNetV2 with the same photo selection and split. **Correction:** the Keras version fine-tuned the run-2 model in place and then scored that one object in both table rows, so its "frozen 0.853, fine-tuned 0.853, no gain" compared the fine-tuned model with itself. - **Session 12:** section 1 now shows the model predicting the next token, step by step, with greedy and sampled answers, so the course says plainly what a language model does; the knowledge base's Session 9 and 10 facts updated (the RAG answer about fine-tuning changed accordingly); a note that the injection results come from one greedy run per prompt.
