# Paper map

**Paper:** (title, authors, year, where the code is)

| | |
|---|---|
| **The question** | What is the paper trying to find out, in one sentence? |
| **The method** | What did they do, in three sentences? What is new compared with what was already known? |
| **The evidence** | Which table or figure supports each claim? List the claim, the table, and the numbers. |
| **The scale** | Model size, data size, number of runs, number of seeds. |
| **The noise** | Do the tables have error bars? Of what size, compared with the differences claimed? |
| **The compute** | Were all arms given the same budget? How do you know? |
| **What would make me doubt it** | Three things that would break the claim. |
| **What I can test here** | Which part of the claim fits a small run, and which part does not? |
