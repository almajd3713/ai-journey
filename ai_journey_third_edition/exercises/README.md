# Your turn: practice for the basic course

One short notebook per session (`b00_your_turn.ipynb` to `b12_your_turn.ipynb`), a bug hunt, and a capstone.

- **Your turn notebooks.** Each has two tasks. Replace every `...` with your own code and run the check under it: `PASS` or `FAIL` with a hint. Run it as often as you like. Everything runs on a laptop CPU in seconds.
- **Solutions** are in `solutions/`. Each file is the same notebook with every task filled in and a short note on why it works. Try the task first.
- **`bug_hunt.ipynb`** is a project with five planted mistakes of the kind Sessions 2 to 7 warn about. Find them, then compare with `solutions/bug_hunt_answers.ipynb`.
- **`capstone/`** has a brief, a rubric and a report template: the whole experiment chain on a dataset you have not seen.

Keep `aij_check.py` in the same folder as the notebooks. It is a few lines of plain Python: no grading server, nothing is sent anywhere.
The requirements are those of the course (`../requirements.txt`).
