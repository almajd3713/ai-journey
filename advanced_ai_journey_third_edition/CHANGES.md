# Changes from the previous advanced course

The previous version is in `../advanced_ai_journey/`. The reasons for the rewrite are set out in `../ADVANCED_REWRITE_PLAN.md` (analysis and plan) and `../ADVANCED_CONTENT_REVIEW.md` (pedagogy review).

## Before You Start (2026-10-24)

- **New notebook `prelim_before_you_start.ipynb`**, unnumbered and optional, before Session 0 (built by `_build/mkprelim.py`). It goes over what the course assumes, the material of basic Sessions 0–10, without assuming the basic course was taken: an experiment on scikit-learn's breast-cancer data, cross-validation, overfitting trees, the training loop on XOR, softmax and cross-entropy in bits, CNN parameter counts, tokens and embeddings, and an LSTM on a negation task. It then measures the LSTM's limit on a key–value recall task (1.000 with 1 pair, 0.213 with 16) and introduces attention, by hand and as one trained head (1.000 on 16 pairs, against 0.215 for the LSTM given the same previous-token note). Earlier versions of the basic course did not reach attention, which Session 1 assumes. Nothing is downloaded; the GPU run takes about two minutes. Numbers quoted from the basic course are marked with their session; the rest come from the saved outputs.
- **Sessions 0 and 1:** the title cell of Session 0 and the callback of Session 1 point to *Before You Start*.

## What changed overall

- **Every result is measured.** The previous notebooks ran no real model: logits, attention weights, scores, latencies and results tables were typed by hand or generated from formulas. The new notebooks run GPT-2, BERT, T5, a small GPT trained here, Qwen2.5 (0.5B and 1.5B, base and instruct), MiniLM and CLIP, and every number in the text was checked against the saved outputs of the final run.
- **PyTorch and Hugging Face `transformers`** replace NumPy-only code. Implementations written from scratch (attention, the transformer block, LoRA) are checked against the library or the real model, and the largest difference is printed.
- **One thread through the course.** GPT-2 runs through Sessions 0–4, the small GPT from Session 3 is reused in Sessions 5 and 11, the Qwen2.5 models in Sessions 6–10 and 12, and Session 7's task in Session 12.
- **A new syllabus.** Fourteen sessions follow the review's recommended syllabus plus the optional multimodal session: the mechanics of transformers, training and scaling, the LLM lifecycle, inference, evaluation, methodology and a paper-reproduction capstone. Generic MLOps and web-service operations were cut.
- **The basic course's format and style.** Title cell with three outcomes and a "To run it yourself" note, numbered sections, pause questions placed before the outputs that answer them, a takeaway, and Going deeper. Hand-typed analogies, closing aphorisms and one-argument-per-line code are gone.
- `manifest.json`, `execution_report.json` and `validation_report.json` were not carried over. `README.md`, `INSTRUCTOR_GUIDE.md` and `requirements.txt` were rewritten.

## Session by session

| New session | Previous session | What changed, and why |
|---|---|---|
| 0 From text to probabilities | 0 Reconstructing the machine | The old session recapped the basic course with typed logits and random embeddings. The new one runs GPT-2's real tokenizer and forward pass, builds BPE merges by hand, and measures cost in bits and why perplexity depends on the tokenizer. |
| 1 Attention inside a real model | 1 Attention as information routing | The old session repeated the basic course's attention example on a hand-typed matrix whose weights (0.17–0.33) showed nothing, and its "it" question was never answered. The new one matches GPT-2's attention to 1e-6, measures the √d_k effect, and finds and ablates induction heads, which turns the warning that attention is not explanation into a measurement. |
| 2 The transformer block | 2 Assembling a transformer block | The old code built post-norm while the text called pre-norm standard, and its claims were stated, not shown. The new block reproduces GPT-2; the residual stream, permutation behaviour and positions (learned, sinusoidal, rotary) are measured, and position moved into the main path. |
| 3 Training a small GPT | 3 From transformer to language model | The old demo was a bigram table from four sentences and five samples. The new session trains an 11.5M-parameter GPT on TinyStories, with measured warm-up, norm placement and sampling effects, and compares it with GPT-2. It is now a 90-minute session. |
| 4 Encoder, decoder, encoder–decoder | 5 What a model is trained to see | Moved up to follow the decoder. | 5 Scaling and data | 6 Scaling models, data and compute | The old compute check omitted the factor 6 in C ≈ 6ND, so every candidate "fitted" a budget it exceeded; its near-duplicate example became an exact duplicate after normalisation; its curves were drawn from formulas. | 6 From base model to assistant | 7 From base model to assistant | The old reward plot was a sigmoid and the DPO rows were typed. The new session compares real base and instruct models, trains reward models on UltraFeedback, runs best-of-N and DPO, and adds checkable rewards (pass@k). |
| 7 Fine-tuning in practice | 8 Adapting, grounding and equipping (first part) | Split out. The old LoRA demo initialised B randomly, so the model changed before training, and omitted the α/r scale.
