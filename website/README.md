# AI Journey website: The Descent

The course site of the AI & Data Science Cell (ENSIA Tech Community). The two courses are a dive down a real loss landscape: the seafloor is the measured loss surface of basic Session 6's XOR network, the route is that network's training path, and the 27 sessions are stations along it. Every session can be downloaded, read in the browser, or (basic course) opened in Colab.

Live: <https://journey.etclub.online> (planned domain: `journey.etclub.online`).

## Layout

| Path | What it is |
|---|---|
| `design-system/` | The visual base, built from etclub.online. Open `design-system/index.html` for the specimen; `design-system/README.md` explains the tokens and components. |
| `content/` | All text is data. `site.json` (names, repo, domain), `people.json` (instructors), `courses/*.json` (extracted from the notebooks), `markers.json` (one sounding and one ping per station, checked against the notebooks). |
| `tools/` | Python scripts: `make_landscape.py` (terrain), `extract_content.py`, `check_markers.py`, `build_downloads.py`, `make_icons.py`, `landscape_spike.py` (the first feasibility test). |
| `public/terrain/` | The terrain: `height.f32` (257 × 257 log-loss grid) and `terrain.json` (trajectory, true losses, provenance). Committed. |
| `public/kit/` | The field kit, generated by `build_downloads.py` (not committed). |
| `src/` | The React app. `scene/` is the three.js dive (lazy loaded), `lib/chart2d.ts` the 2D chart, `ui/` the page sections. |
| `PLAN.md` | The design plan and its decisions. |

## Build

```bash
# once: Python with nbconvert for the kit (the course venv has it), Node 22
python -I tools/extract_content.py     # notebooks -> content/courses/*.json (commit the result)
python -I tools/check_markers.py       # every quoted number must be in its notebook
python -I tools/build_downloads.py     # public/kit + content/kit.json
npm ci
npm run dev                            # or: npm run build && npm run preview
```

`tools/make_landscape.py` needs PyTorch and only has to run if the terrain should change; it checks that it reproduces the notebook's printed losses before writing anything.

Pushing to `main` deploys with GitHub Pages (`.github/workflows/pages.yml`): the workflow re-extracts the content and fails if it is out of date, checks the markers, builds the kit and the site.

## Common changes

- **Add an instructor:** add an object to `content/people.json` (`name`, `role`, `courses`, optionally `sessions` such as `["advanced-06"]` and a `photo` under `public/people/`). Lower `openSlots` as places are filled.
- **A notebook changed:** run `extract_content.py` and `check_markers.py`; if a quoted number changed, update `content/markers.json`.
- **Rename the cell or move the domain:** `content/site.json`.

## Custom domain

To serve the site at `journey.etclub.online`: whoever manages `etclub.online`'s DNS adds a `CNAME` record `journey → almajd3713.github.io`, then the domain is set in the repository's Settings → Pages (or with `gh api`), with HTTPS enforced. Set it only after the DNS record exists, because GitHub then redirects the github.io address to the domain.
