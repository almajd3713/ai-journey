# AI Journey

The AI Journey courses of the AI & Data Science Cell, ENSIA Tech Community, and their website.

| Folder | What it is |
|---|---|
| [`ai_journey_third_edition/`](ai_journey_third_edition/) | **AI Journey**: machine learning from the ground up. 13 sessions (0–12) for software engineers new to ML. |
| [`advanced_ai_journey_third_edition/`](advanced_ai_journey_third_edition/) | **Advanced AI Journey**: inside the language models. 14 sessions (0–13), for those who finished the basic course. |
| [`website/`](website/) | The course site, *The Descent*: <https://almajd3713.github.io/ai-journey/> |

Every notebook is saved with its outputs, so the courses can be read without running anything. Each course folder's README covers setup, downloads and run times.

Open a basic-course notebook in Colab with
`https://colab.research.google.com/github/almajd3713/ai-journey/blob/main/ai_journey_third_edition/<notebook>.ipynb`.
The advanced notebooks are made to be read from their saved outputs; re-running them needs a GPU and the files next to them (`aij_common.py`, `tinygpt.py`, `data/`).
